Entry for the [make.fun](https://make.fun) competition
[One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc).

`main.ts` (Node 22) writes a single original one-line joke about office life
to `/output/entry.txt`:

> I hit reply-all to ask to be removed from the thread, and now I'm the thread's most active contributor.

The line is 103 characters, one line, inside the competition's 1–199 character gate.
It turns on a real detail of office life (the reply-all thread) and lands the
laugh in the last few words.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```
